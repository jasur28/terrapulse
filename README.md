# TerraPulse

**Интеллектуальный мониторинг состояния зданий и мостов в реальном времени.**

TerraPulse непрерывно измеряет вибрацию конструкции собственными MEMS-акселерометрами,
анализирует состояние в облаке, вычисляет сейсмическую интенсивность и индекс
безопасности, обнаруживает аномалии и предупреждает об опасности заранее — вплоть до
мгновенной оценки здания после землетрясения.

Мы разрабатываем весь стек сами: от акселерометра и электроники до встроенного ПО и
облачной платформы.

- **Свои приборы** — MEMS-акселерометры собственной разработки
- **Облачная платформа** — клиенту не нужны серверы, доступ с любого устройства
- **Открытые стандарты** — данные в универсальном формате
- **Статус:** рабочий прототип (MVP) — живой поток данных в реальном времени
